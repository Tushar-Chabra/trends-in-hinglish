# Daily GitHub Trends in Hinglish

Har din ke top 10 trending GitHub projects, simple Hinglish mein, non-tech logon ke liye.
Kya karte hain, kisne banaye, kitne safe hain, aur kaun kis kaam ka hai.

**Live page:** https://tushar-chabra.github.io/trends-in-hinglish/

## Ye page kya dikhata hai
- Aaj ke Top 3 aur Daily / Weekly / Monthly / Yearly top 10
- Har project ke liye: kya karta hai, kyun bana, kyun zaroorat padi, kis kaam aayega
- Language chart, stars ka comparison, risk label (Kam risk / Dhyaan dein / Zyada risk) aur chetawani
- Report ko Markdown ya PDF mein download karne ka option

## Data kahan se aata hai
Trendshift.io aur har project ka public GitHub page. Page roz ek baar update hota hai; link hamesha wahi rehta hai.

## Safety aur zimmedari (zaroor padhein)
- Ye sirf jaankari hai, salah nahi. Risk label andaza hai, security audit nahi.
- Kuch bhi install karne se pehle uska official page khud padhein.
- Anjaan website se command copy karke na chalayein. Software sirf official GitHub page se download karein.
- Apna password ya API key kisi ko na dein.
- Kisi bhi project ko install ya use karna aapka apna faisla hai. Isse hone wale kisi bhi nuksaan ki zimmedari is page ya iske banane wale ki nahi hai.
- Page kisi company ya project se juda nahi hai. Koi tracking ya cookies nahi.

## Privacy / technical notes
- Page ek single file (`index.html`) hai; isme koi tracking, cookies ya third-party script nahi.
- Sab data page mein hi judaa hota hai aur dikhane se pehle saaf (sanitize) kiya jata hai.
- Galti mili to GitHub Issues mein batayein.
